# Customer Segmentation (K-Means Clustering)

Segmenting mall customers into groups with **K-Means clustering** — the classic unsupervised-learning workflow, from EDA to cluster interpretation.

## Overview

## Origin

This project was originally developed inside the `Data-Science` notebook collection and now lives in its own repository for easier discovery and use.

Using the well-known `Mall_Customers.csv` data (age, annual income, spending score), the notebook explores the data, chooses a cluster count, fits K-Means and visualizes the resulting customer segments — the standard starting point for data-driven marketing segmentation.

## What's Inside

- `customer_segmentation.ipynb` — EDA → feature selection → K-Means → segment plots & interpretation

## Getting Started

```bash
git clone https://github.com/datascientist970/customer-segmentation-clustering.git
cd customer-segmentation-clustering
pip install -r requirements.txt
jupyter notebook customer_segmentation.ipynb
```

Place `Mall_Customers.csv` in the working directory before running (dataset not included in this repository).
